# Security Policy

## Supported Versions

OvaCanvas does not provide long-term security support for older versions. Only
the newest state of the `main` branch is supported.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/wilmhurst-ski/ovacanvas/security/advisories/new>

If private reporting is not enabled, contact the maintainer using the methods
listed on their GitHub profile (<https://github.com/wilmhurst-ski>) and ask for
a private channel before sending any details.

After receiving a report we will try to confirm the problem and let you know
what we intend to do about it. OvaCanvas is a young project maintained by one
person, so please do not expect a same-day response.
